# 行间旅行 · 界面约定

基于已有产品与 UI/UX Pro Max 2026-09-18 本地检索。使用Vue 3 / uni-app，保持微信与H5兼容。

- 2026-09-19用户确认蓝白简洁方向；背景 `#f5f7fb`，内容面 `#ffffff`，主色 `#367be7`，次级文字 `#6b7b90`，边线 `#e5ecf4`。语义变量统一定义在 `src/styles.css` 的 page。
- 不采用检索返回的获客营销布局，不依赖Google Fonts，不增加装饰性连续动画。
- 主标题与正文均使用系统无衬线字体。新页面正文约15–16px，辅助信息12–13px，文字长时允许换行。
- 卡片圆角20–24px，主要分区间隔24–28px，控件间隔至少8px。
- 点击区域44–48px，保存期间禁用重复提交；有可见标签、错误信息与完成文字，不能只靠颜色辨认状态。
- 清单：整趟进度 → 自定义入口 → 成员/待收拾筛选 → 分类条目 → 可编辑模板。
- 规划：固定地图＋独立滚动日程；日期/总览与地图/同屏/列表切换；今晚住宿与退房提醒在当天开头。固定导航为规划、预订、账本、准备。位置管理在地图页保留，待规划池尚未实现。
- 支持375px和横屏，不强制深色主题；减少动态效果偏好下取消按钮过渡。微信大字体与读屏以真机验收结果为准。
