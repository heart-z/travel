# 行间 · 多人旅行规划网页

独立于旧 uni-app 小程序的本地网页应用。主要功能：共同编辑、地图与每日行程联动、交通与住宿、按人分配物品、攻略、账本、JSON 副本导入与导出。

## 本机运行

在本目录使用 Node.js 24 或更新版本。已在 Node 26.3.0 验证。

```powershell
npm ci
npm run bootstrap
npm run dev
```

打开 http://127.0.0.1:5174 。初始化程序在终端创建自己的账号，密码不回显。使用已有账号时不要再次初始化，通过旅行内「同行人」生成邀请。

如本地终端权限不允许 npm 写缓存，需要允许标准 npm 缓存访问；不要在上级旧小程序目录安装依赖。

## 独立示例

```powershell
node --experimental-strip-types scripts/demo.ts
$env:XJ_DATABASE='./data/demo.sqlite'
npm run dev
```

`data/demo-access.json` 保存两个示例账号的登录资料。两者仅访问合成的杭州示例；样例不是订单或实际出行建议。再次执行脚本不会覆盖已有示例。自己的正式资料默认保存在另一个 `data/travel.sqlite`。

## 已实现和环境边界

- 用户名密码登录、一次性邀请、拥有者/编辑/查看权限、移除成员及撤销邀请。
- HTTP 事务写入、记录版本冲突提示、请求去重、SSE 更新通知。两个隔离浏览器已完成协作验收。
- 日程按天与待规划分开；地图编号联动、点选保存位置、拖动/按钮排序、跨天移动。
- 逐段交通方式、有效道路结果展示接口。未配置道路服务时明确提示，不伪造路线、里程或耗时。
- 多晚住宿、跨夜交通、时区偏移校验、日程入住/退房/出发/到达提醒。
- 物品六类、按人筛选与分工、穿着/装包、共同勾选、按天数/洗换间隔的衣物建议。
- 单币种整数分账本、均分/指定份额、结清、攻略来源及关联。
- 手动选择旧备份，预览后导入新副本，保留源资料；不会自动读取私人备份或与旧小程序同步。

当前只在本机监听。异地两部手机需要共同可达的私有 HTTPS 服务器；本机地址不能发给异地同行人直接使用。没有采购、发布、配置公网隧道或开通地图计费。

道路服务需配置 `XJ_OSRM_DRIVING` 或 `XJ_OSRM_WALKING`，必须是相应 profile 的实际实例；将 driving URL 改名不能获得步行能力。服务未配置前，路线属于“顺序规划可用、道路查询待配置”。详见 [私有运行说明](docs/run-private.md)。

## 验证

```powershell
npm run type-check
npm test
npm run build
$env:NO_PROXY='localhost,127.0.0.1'
npm run test:e2e
npm run check:isolation
```

浏览器测试目前使用本机安装的 Chrome，路径在 playwright.config.ts；换机器时需调整。测试数据库仅在内存或临时目录创建，不使用示例或私人数据库。Windows 沙箱可能阻止测试进程清理，应在允许启动/结束测试浏览器的环境运行。

示例账号和本地数据库位于 `data/`，该目录不纳入公开仓库。
